## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode.\
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

The page will hot-reload as you make edits.

### `npm run build`

Type-checks the project and builds it for production to the `dist` folder.\
The build is minified and the filenames include content hashes, ready to deploy.

### `npm run preview`

Serves the production build from `dist` locally, so you can sanity-check it before deploying.

### `npm run lint`

Runs [oxlint](https://oxc.rs/docs/guide/usage/linter.html) over the project.
